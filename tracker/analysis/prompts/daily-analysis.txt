## Classification Rules

**deep_work**: Active creation — writing original content, designing in Figma with frame changes, coding, building. Requires evidence of output (word count delta, frame name changes, active keystrokes in a doc).

**light_work**: Reviewing someone else's work, giving feedback in chat, editing received docs, reading reports from team members.

**research**: Reading/watching content directly relevant to current work. Content about a topic that matches the user's stated goals or projects = research. Content matching the user's listed distractions = rabbit_hole or waste_of_time depending on shape.

**drift**: The FIRST one or two off-task actions after leaving work — the moment of getting distracted. The user hasn't committed to anything yet; they could still bounce straight back to work. Examples: opening a new tab and searching a score, glancing at Twitter, clicking a link that caught their eye. Drift is about the *transition* away from work, not duration. A drift block is usually short (a few snapshots) and ends one of three ways: (a) returns to work, (b) escalates into waste_of_time, or (c) escalates into a rabbit_hole.

**waste_of_time**: A standalone off-task activity that is NOT a deep dive into one topic. Watching a single YouTube video about Porsche Sally, watching one Leicester City highlight reel, watching one episode of a show, scrolling Instagram for 20 minutes, reading a single news article unrelated to anything. The defining feature: it's bounded — one video, one article, one session — even if it lasts 30+ minutes. Multiple unrelated wastes of time in a day are still each a separate `waste_of_time` block, NOT a rabbit hole.

**rabbit_hole**: A deep dive into ONE specific topic, pursued across MULTIPLE sources or formats. The user becomes obsessed with one subject and chases it: watches a video → reads the Wikipedia → looks at reviews → searches for related news → checks comments → opens 5 tabs about the same person/event/thing. Example: Michael Jackson — watched a video, read about his movie, saw reviews, looked up the 2009 comeback announcement. That is a rabbit hole. A 45-minute video about cars is NOT a rabbit hole, it's `waste_of_time`. The signal for rabbit_hole is *topic continuity across multiple distinct activities*, not duration. Most days have zero rabbit holes. If you can't name the single topic in 3 words, it isn't one.

How to choose between the three when in doubt:
- One activity, one topic → `waste_of_time`
- One activity, then back to work → `drift` (the transition)
- Multiple activities, all about the same topic → `rabbit_hole`
- Multiple activities, all different topics → tag each separately as `drift` or `waste_of_time`

**meeting**: Zoom, calls, syncs. Screen locked + Zoom active = meeting.

**break**: Intentional (user marked it) or screen locked > 5 minutes.

**AI chat classification**: For Claude/ChatGPT/Gemini sessions, use text_field_sample to determine topic. If topic matches today's goals → deep_work or research. If topic is adjacent but not on today's goals → light_work. If topic is unrelated AND a single conversation → `waste_of_time`. If the AI chat keeps returning to the same off-topic subject across a long session and clearly fed a deep-dive (the user kept asking follow-ups about one thing) → `rabbit_hole`. Don't auto-default to rabbit_hole just because it feels productive — most off-topic AI chats are `waste_of_time`.

**Sub-categories** only apply to deep_work and light_work:
- original_thinking: generating new ideas, writing from scratch
- clarifying_productising: sharpening existing ideas, structuring, spec-ing
- reviewing_feedback: reading others' work, commenting, editing
- research_synthesis: gathering and organising inputs

Be especially harsh about:
1. Any of the user's listed distractions appearing during stated work hours
2. AI chats not related to stated goals
3. YouTube chains where consecutive videos are unrelated (each is its own `waste_of_time`)
4. YouTube chains where consecutive videos chase ONE topic — that's a `rabbit_hole`, name the topic
5. "Recovery" browsing after a distraction (often longer than the distraction itself)
6. Gaps between stated goal start time and actual start time

Important: do NOT use the word "rabbit hole" loosely in the narrative. Reserve it for true topic-obsession sessions. Most days will have zero. If you write `rabbit_hole_minutes > 0`, the narrative MUST name the single topic that defines the rabbit hole.
